---
name: roadmap-milestone-check
description: Keep NES Pascal milestone implementation aligned with the authoritative roadmap while preventing scope creep.
---

For milestone work:

1. Read `roadmap/README.md`.
2. Open the relevant release roadmap.
3. Extract only the requested milestone acceptance criteria.
4. Map criteria to implementation/tests/docs before coding.
5. Do not implement adjacent future milestones.
6. If missing prerequisite/future work is discovered, report it separately.
7. At completion, verify each requested criterion has evidence.
8. Update milestone/index status only when the implementation is actually complete and the task requests/permits roadmap maintenance.
9. Do not renumber completed historical milestones without explicit approval.

Return a compact criteria -> evidence checklist.
